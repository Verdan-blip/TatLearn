# 00. Общее

## 1. О продукте
Мобильное приложение (Android и iOS) для изучения татарского языка. Аудитория — русскоязычные пользователи. Пользователь проходит короткие уроки из упражнений, получает очки опыта (XP), поддерживает ежедневную серию занятий. Маскот — «Мыраужан» (иллюстрации пока не нарисованы).

## 2. Переходы между экранами

**Гостевой режим (по умолчанию, регистрация закрыта фича-флагом `tamyr.registrationEnabled`):**
```
Запуск
 ├─ профиль есть (или есть сессия) ──► Главная
 ├─ онбординг уже показывали ────────► Знакомство → Главная
 └─ иначе ───────────────────────────► Онбординг → Знакомство → Главная
```
Вход и регистрация недоступны. Схема ниже описывает поток с включённым флагом.

```
Запуск
 ├─ пользователь уже вошёл ─────────► Главная
 ├─ онбординг уже показывали ───────► Вход
 └─ иначе ──────────────────────────► Онбординг
Онбординг ─«Начать»─────────────────► Регистрация
Онбординг ─«У меня уже есть аккаунт»► Вход
Вход / Регистрация ─успех───────────► Главная (вернуться назад нельзя)
Главная ─«Урок N»───────────────────► Урок
Урок ─все шаги пройдены─► Результат
Урок ─закрыть + «Выйти»─────────────► предыдущий экран
Результат ─«Продолжить»─────────────► Главная
Результат ─«Повторить ошибки»───────► Урок только с ошибочными шагами
```
Из Результата нельзя вернуться в завершённый урок.

Стартовый экран выбирается один раз при запуске приложения.

## 3. Правила обучения (сквозные)
- **Жизней нет.** Ошибки не прерывают урок (решение в [13-learning-model.md](13-learning-model.md)). Каждый неверный ответ попадает в список ошибок и снижает точность.
- **XP:** 3 очка за каждый верно решённый шаг. Начисляются сразу после проверки шага, даже если урок потом не завершён.
- **Уровень:** новый уровень каждые 100 XP. *Временная формула — открытый вопрос.*
- **Серия дней:** занятие в тот же день серию не меняет; в следующий день — серия +1; при пропуске дня серия сбрасывается до 1. Пока занятий не было вчера или сегодня, на экранах показывается 0 (в базе остаётся старое значение до следующего занятия). Дни считаются по времени UTC.
- **Точность:** доля верных шагов среди проверенных.
- **Статус урока:** «не начат» → «в процессе» (после первого шага) → «пройден» (точность не ниже 80 %). Сохраняется лучший результат.

## 4. Данные
- **Учебный контент** (модули, уроки, слова, фразы) пока хранится в самом приложении, загрузка имитирует задержку сети 0,3–0,8 с. Подключение к реальному серверу предусмотрено, но выключено.
- **Прогресс** (XP, серия, пройденные шаги) и **сессия пользователя** (имя, e-mail) хранятся на устройстве и сохраняются между запусками.
- Признак «онбординг уже показан» тоже хранится на устройстве.
- **Ошибки загрузки** имеют код (нет связи, не найдено, неизвестная ошибка, в уроке нет упражнений); код показывается пользователю.

## 5. Тексты и оформление
- Интерфейс двуязычный: татарский заголовок + русское пояснение.
- Весь татарский контент **не проверен носителем языка**.
- Места, которых нет в макетах, отмечены как «требуется дизайн».

## 6. Открытые вопросы
- Формула XP и уровней.
- Порог прохождения урока (сейчас 80 %) и способ его задания (в приложении или с сервера).
- Проверка контента носителем языка.
