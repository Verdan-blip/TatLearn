# 12. Debug UI kit (ShowcaseScreen)

Код: `…/feature/showcase/` (`ShowcaseScreen.kt`, `ShowcaseViewModel.kt`). Это **служебный экран**, не часть продукта.

## Назначение
Каталог компонентов дизайн-системы и отладочные переключатели для разработчика.

## Вход / выход
- **Вход:** вкладка «Профиль» главной (заглушка), кнопка «Инструменты отладки». Показывается только в debug-сборках (`AppNavigation(showDebugTools = true)`). Прежняя плавающая кнопка «UI» убрана: она мешала на всех экранах.
- **Выход:** кнопка «Назад» → pop.

## Что показывает
Разделы: кнопки (все стили), теги, прогресс, ромбики и лоадер, карточка, состояния (показать Loading / Error), татарские буквы (ә ө ү җ ң һ и заглавные, пример текста).

## Отладочные функции («Данные (отладка)»)
| Функция | Что делает |
|---|---|
| Статистика | Выводит `XP · серия · уровень` из БД. |
| Загрузка главной | Показывает статус загрузки `getModules()` и «Урок N · …, модулей: M» (первый урок первого модуля); кнопка «Перезагрузить главную». |
| «Записать результат (+9 XP)» | Записывает тестовый результат упражнения в БД (проверка XP/серии). |
| «Ошибки сети: вкл/выкл» | Переключает `FakeBackendConfig.simulateErrors` — все fake-запросы падают с `NET_TIMEOUT` (проверка экранов 07/08 на Home и Lesson). |

## Напоминание («Напоминание (проверка на устройстве)»)
Две кнопки: «Показать тестовое уведомление» (запрашивает разрешение и показывает настоящий текст; на Android сразу, на iOS через 5 секунд, приложение нужно свернуть: на переднем плане iOS уведомление не показывает) и «Сбросить предложение напоминаний и выключить» (шторка после урока снова может появиться).

## Вибро («Вибро (проверка на устройстве…)»)
Три кнопки проигрывают паттерны «верный ответ», «неверный ответ», «урок пройден» через `Haptics` (учитывают настройку «Вибро-отклик» в профиле). Ощущения проверять на реальном устройстве.

## Действия («Действия (отладка)»)
Каждое действие просит подтверждения нижним листом (`TamyrConfirmSheet`) с описанием, что именно будет стёрто.

| Действие | Что делает |
|---|---|
| Сбросить прогресс уроков | `ProgressRepository.resetLessonProgress()`: удаляет статусы уроков и историю заданий; XP и серия остаются. |
| Сбросить XP и серию | `ProgressRepository.resetStats()`: обнуляет `UserStats`; статусы уроков остаются. |
| Выйти из аккаунта | `AuthRepository.signOut()`, затем стек навигации заменяется экраном входа. Прогресс остаётся. |
| Сбросить онбординг и выйти | Выход плюс `OnboardingStorage.reset()`; стек заменяется онбордингом. Прогресс остаётся. |
