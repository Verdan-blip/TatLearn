# feature/home

Главная: приветствие, серия и XP, карточка «Продолжить», плитки модулей, нижнее меню. Спека: `.docs/03-home.md`, макет `design/screens/03.png`. Модель обучения (курс, модуль, урок, задание, порог, блокировка, обмен с сервером): `.docs/13-learning-model.md`.

## Поток
`HomeRoute` (stateful) -> `HomeScreen` (stateless) <- `HomeViewModel`. Контент (`HomeContent`) читается из `LessonsRepository.getHome()`, серия и XP из `ProgressRepository.observeStats()`.

## Решения (24.10.2026)
- Модуль = набор уроков, пройден при всех пройденных уроках; урок пройден при >=80 % правильных; следующий модуль открывается мягко (после всех уроков предыдущего, закрытые можно смотреть).
- Урок целиком приходит с сервера одним запросом, проходится без сети, результат отправляется с экрана результата.
- Жизней и батареи в MVP нет.

## UX-решения (аудит ux-designer, 24.10.2026)
- «Продолжить» — единственный герой экрана, поэтому карточка серии стала компактной и стоит под ним; подпись «До уровня N» убрана (полоса говорит сама).
- Закрытый модуль читается на полном контрасте (без прозрачности) и нажимается: показывает свою подсказку уведомлением.
- Иконка «Сүзлек» — раскрытая книга. Подписи нижнего меню пока только по-татарски (двуязычие не добавляли, needs native-speaker review).

## Текущее состояние и расхождения
- Модули и текущий урок читаются из статичного `home.json`; связи модуль -> уроки нет, проценты и «3 из 5» заданы вручную.
- Нажатия на плитки и «Все» показывают уведомление-заглушку (`TODO(design)`: экранов нет).
- Вкладки «Сүзлек», «Ярыш», «Профиль» открывают заглушку `ComingSoonState` (экран 16: спящий маскот, тег «Тиздән · Скоро», заголовок и пояснение; кнопки «На главную» нет, это дубль вкладки «Өй», по замечанию ux-designer). Выбранная вкладка хранится в `HomeUiState.tab`, меню остаётся на экране. Весь татарский текст заглушек подтверждён автором-носителем. Системная кнопка «назад» с заглушки пока не возвращает на «Өй».
- Профиль: выхода из аккаунта нет (ux-designer советует мини-профиль с «Выйти» через `TamyrConfirmSheet`), решено отложить: мини-профиль (имя, почта, «Выйти») будет отдельной задачей, пока заглушка.
- Нет состояния «всё пройдено» и пустого списка модулей.
