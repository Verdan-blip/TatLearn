# feature/profile

Вкладка «Профиль», изменение профиля, аватар. Спека: `.docs/20-profile.md`, макеты `design/screens/26.png`, `27.png`, `30-33.png`, `38.png`, `42.png`.

## Поток
- `ProfileScene` (содержимое вкладки внутри главной; нижнее меню рисует `HomeContent`, слот `profileTab`) -> `ProfileContent` <- `ProfileViewModel(ProfileRepository, ProgressRepository, AuthRepository)`. «Изменить профиль» открывает `ProfileEditKey`.
- `ProfileEditScene` -> `ProfileEditContent` <- `ProfileEditViewModel`. Сохранение кнопкой; несохранённые изменения подтверждаются листом `TamyrConfirmSheet`, системный «назад» идёт через `NavigationBackHandler`.
- `ProfileRepository` (domain) и `SettingsProfileRepository` (data/local, multiplatform-settings): имя, аватар, локальный UUID; `saved` — событие для уведомления «Сохранено».
- `ProfileAvatar` (цвет с буквой или кадр головы позы Мыраужана; кадры `PoseCrop` заданы в сетке 400×400 поверх PNG маскота и подобраны 02.11.2026 под рыжего кота из Nano Banana, при смене картинок их надо пересматривать, макеты 32 и 33 показывают старого кота) и `AvatarPicker` (цвета и позы на одной сетке из 6 колонок, радиогруппа) используются и на знакомстве, и в шапке главной.

## Решения (25.10.2026)
- Правила имени в `ProfileRules` (domain): обрезка и схлопывание пробелов, 1-20 символов, счётчик с 15-го; имя по умолчанию «Друг».
- 4 цвета аватара из токенов; на золоте буква тёмная (светлая не проходит контраст), у всех цветов и поз обводка 2 dp `textSecondary`.
- 6 поз: greeting, cheer, searching, sleeping, correct, timer (по совету дизайнера: различимы в 36 dp; `sad` и `wrong` не берём, тон «без стыда»).
- Хранилище профиля отдельно от сессии: при будущей привязке аккаунта профиль и прогресс переносятся по локальному UUID.
- Вход в инструменты отладки живёт на вкладке «Профиль» только в debug-сборке.

- **Напоминание об уроке (30.10.2026):** строка с переключателем и кнопками времени 08/13/19/21 (показываются, когда включено). Включение просит системное разрешение; при отказе показывается уведомление-ошибка. Логика в `core/notifications/Reminders`. Строка не нарисована в макете (`TODO(design)`).

- **Звуки (02.11.2026):** строка «Звуки» рядом с «Вибро-отклик», `SoundEffectsSettings` (по умолчанию включено), общая `ToggleRow`. Звучат три события (верно, неверно, урок пройден), как и вибро; логика в `core/sound`. Строка не нарисована в макете (`TODO(design)`).

- **Голос диктора (04.11.2026):** строка «Голос диктора» с кнопками «Мужской / Женский» (`NarratorSettings`, по умолчанию мужской), выбор действует на всю озвучку слов в уроках (`NarratorVoice.resolve` подменяет `audio/x.m4a` на `audio/female/x.m4a`). При выборе голоса играет образец слова «Исәнмесез» этим голосом (`NarratorPreview`, повторный тап по выбранному слушает снова). Строка не нарисована в макете (`TODO(design)`). Кнопка «О приложении» открывает `feature/about`.

## Открытые вопросы
- Новые позы (с книгой, с чашкой чая, гордый, подмигивает, в наушниках, любопытный) ждут иллюстраций; идея открывать позы за достижения.
- Цель изучения, ежедневная цель, напоминания, «Удалить данные», политика конфиденциальности (needs lawyer review).
- Татарское название вкладки «Профиль» (needs native-speaker review). Формула уровня (`xp / 100 + 1`) временная.
- Расхождение: на макете 03 при 340 XP был «Ур. 6», по формуле уровень 4.
- Строка «Вибро-отклик» (`HapticsSettings`, по умолчанию включено; решение владельца: название только по-русски) живёт на вкладке «Профиль». Паттерны и правила вибро: `.docs/00-overview.md` (раздел 6), код `core/haptics` (`PatternHaptics` над платформенными `PlatformHaptics`: Android `Vibrator`, iOS `UIFeedbackGenerator`).

- **Настройки сгруппированы (04.11.2026, макеты 26/33/38/42, совет ux-designer):** заголовок «Настройки» и одна карточка с разделителями: «Вибро-отклик», «Звуки», «Голос диктора» (`ProfileSettingsGroup`, `ProfileToggleRow`, `ProfileNarratorBlock`); «Напоминание» отдельной карточкой (`ProfileReminderCard`). У строк плашка с иконкой (`ProfileIconTile`, штриховые иконки `StrokeIcon` из SVG-путей 24×24). Кнопки голоса 52 dp с иконкой динамика, подпись «Нажмите, чтобы услышать и выбрать», `contentDescription` через `TamyrChoiceChips(descriptions)`. «О приложении» это строка со стрелкой (`ProfileAboutRow`), а не 3D-кнопка; подпись «Данные хранятся на этом устройстве» стоит под ней. Экран «О приложении» в макете 43 (лицензия свёрнута) и 44 (развёрнута): в приложении так же: лицензия свёрнута до заголовка, «Показать полный текст» раскрывает её (`AboutLicenseCard`, состояние в `AboutScene`), адрес проекта это ссылка (`AboutVoiceCard`). Версии приложения и тёмной темы нет (`TODO(design)`).
