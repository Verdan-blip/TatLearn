# feature/lesson

Один урок целиком: `LessonKey(lessonId, stepIds)` -> `LessonRoute` -> `LessonScreen` <- `LessonViewModel`. Контент из `LessonsRepository.getLessonContent`, `LessonPlanner` (domain) превращает его в шаги `ExerciseStep`. Спека упражнений: `.docs/04-lesson-matching.md` … `.docs/11-lesson-translation.md`, план структуры урока: `.docs/21-course-roadmap.md`, раздел 4. Правила (без жизней, порог 80%, XP, нормализация ответа) описаны в корневом `CLAUDE.md`.

## Структура урока (04.11.2026, макеты 50–54)
- Порядок шагов: карточки новых слов (`ExerciseStep.WordIntro`, по одной на слово сопоставления, не больше слов урока; на последней сводка чипами со звуком), карточка-правило (`ExerciseStep.Rule`, если в JSON урока есть `rule`), сопоставление, затем упражнения вперемешку. Чередование считает `LessonPlanner.interleaved`: положение шага внутри своего вида задаёт его место, продуктивные виды (сборка, перевод) сдвинуты к концу, выбор ответа не стоит последним, одинаковые виды подряд не идут, пока есть выбор. «Повторить ошибки» (`stepIds`) идёт без карточек и в исходном порядке видов.
- Карточки не проверяются: «Дальше» работает сразу (`LessonViewModel.next`), в точность, XP и список ошибок они не входят; полоса прогресса считает их шагами. Кнопка внизу: `ExerciseContinueBar` («Дәвам · Дальше», на последней карточке «Начнём упражнения», у правила «Аңладым · Понятно»).
- Звук на карточках: `LessonUiEvent.PlayWordClicked(url)` (голос диктора по настройке профиля); какая запись звучит, видно по `LessonUiState.lastWordUrl` и состоянию плеера. Перевод на карточке всегда с заглавной буквы (`capitalizedFirst`, данные хранят слова строчными). Подсказка Мыраужана на карточке это заметка сопоставления без префикса «Мыраужан: ».
- Возврат слова: после ошибки в квизе или аудировании тот же вопрос возвращается через 3 шага (`RETRY_GAP`) с золотой меткой «Кабатлыйбыз · Повторим» (`isRetry`). Такой шаг не записывается в прогресс, не даёт XP и не меняет точность; в «повторе ошибок» возврата нет.
- Правило пока есть только в уроке «Еда и напитки» (`lesson_3`, «-м = я», `needsNativeReview`), поля JSON: `rule.title`, `rule.text`, `rule.examples[{tatar, russian, highlight, audioUrl}]`. Открывать правило снова из модуля пока нельзя (`TODO(design)`: в макете это обещалось, в приложении нет, поэтому подсказка про это убрана).

## Открыто
- Крупный шрифт и малый экран: слово на карточке при 200% рвётся посередине, нужен размер с подгонкой под ширину (дизайнер советует до 52 px, на 320 dp около 44), подсказка Мыраужана при крупном шрифте скрывается, кнопки переносятся на две строки, содержимое прокручивается (`TODO(design)`).
- Новых слов обычно ровно 5 (по числу пар); группы по 3–5 слов, когда слов больше, не нарезаются.
- Тёмной темы нет. Татарские подписи («Яңа сүз», «Кагыйдә», «Кабатлыйбыз», «Дәвам», «Аңладым»): needs native-speaker review. Проверено на эмуляторе Android (карточки, сводка, правило); возврат слова проверен тестами, на устройстве нет.
