# feature/result

Итог урока. Спека: `.docs/06-result.md`, макеты `design/screens/06.png` (засчитан) и `14.png` (не засчитан). Правила: `.docs/13-learning-model.md`.

## Поток
`ResultScene` (stateful) -> `ResultContent` (stateless) <- `ResultViewModel(key: ResultKey)`. Все цифры приходят готовыми в `ResultKey`; серия берётся из `ProgressRepository`.

## Решения
- **Засчитан или нет решает `PassRules`** (точность >= `XpRules.PASS_THRESHOLD_PERCENT`, 80; повтор ошибок засчитывается при нуле неисправленных). Та же функция вызывается в `LessonViewModel` при `completeLesson`, чтобы экран и сохранённый статус не расходились.
- **Экран «не засчитан»** по рекомендации методиста и UX-дизайнера: тон «хорошая попытка», порог показан как расстояние до цели («нужно ещё N верных ответов»), без красного и конфетти, главная кнопка «Повторить ошибки», выход «На главную» вторичный. Серия и XP за честную попытку не отнимаются.
- В повторе ошибок вместо «нужно ещё верных ответов» показывается число неисправленных ошибок.

- **Предложение напоминаний (30.10.2026):** один раз, на экране результата первого засчитанного урока, шторка с кнопками времени 08/13/19/21 (`ResultUiState.reminderPrompt`). Шторка выезжает через `TamyrMotion.REMINDER_PROMPT_DELAY_MS` (0.8 с) после показа экрана, чтобы не казалось, что на экран перешли уже со шторкой; флаг «показывали» ставится в момент показа (ушёл раньше, предложение не тратится). Не нарисовано в макете (`TODO(design)`).

- **Анимация XP (30.10.2026, вариант A из трёх, макеты 06, 14, 41):** число XP набегает от 0 до итога за 0,8 с (`rememberXpCountProgress`), вместе с ним тикает строка уровня «Ур. N · XP» с золотой полосой (`LevelCard`, чистая функция `xpAnimationFrame` в domain). Если урок перевёл через границу уровня, полоса доезжает до конца и тихо начинается заново; отдельного события «Новый уровень» нет сознательно: пока уровень ничего не открывает, это пустое поздравление (мнение учителя, аналитика, маркетолога; решение владельца: «пусть пока просто есть»). При незасчитанном уроке счёт спокойный, без золота, с подписью «Это тоже опыт» (только по-русски), строки уровня на этом экране нет (экран и так плотный). «Уменьшить анимацию»: итоги сразу. Скринридер читает плитку XP как «Получено N XP». Содержимое по центру прокручивается на маленьких экранах.

- **Звук «урок пройден» (02.11.2026):** вместе с вибро `celebrate` один раз при показе засчитанного урока играет `SoundEffects.complete()` (около 1 с, колокольчики); у «не засчитан» звука нет (тон «хорошая попытка»). Выключается переключателем «Звуки» в профиле.

## Открытые вопросы
- Правило «повтор ошибок засчитывает урок» и серия за любую попытку: рабочие допущения, ждут подтверждения.
- Список слов с ошибками на экране «не засчитан» (вариант C): нужны слова шагов в `ResultKey`.
- Татарский заголовок для «не засчитан» (needs native-speaker review).
- «Стрик продлён» показывается только при `ResultKey.streakExtended`: `ProgressRepository.recordExerciseResult` возвращает `ExerciseOutcome.streakExtended` (последняя активность была вчера), `LessonViewModel` собирает флаг за урок.
