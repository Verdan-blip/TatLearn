# Как дорисовывать дизайн Тамыр

Сначала прочитай скилл `design` (что считается дизайном). Правила ниже выведены из самого макета; если макет изменился, сверься с ним, а не с этим текстом.

## Процесс

1. Найди в макете ближайший аналог (экран 02 для форм, 05 для панели ответа, 08 для состояний, 03 для карточек) и скопируй его разметку, а не рисуй с нуля.
2. Предложи **несколько вариантов** (3–4), отрисованных на копии реального экрана, где элемент появится. Черновики кладёшь в scratchpad, не в `design/`. Рендер: `Google Chrome --headless --screenshot` (Playwright в системе не установлен).
3. Покажи варианты агенту `ux-designer` (`.claude/agents/ux-designer.md`) и, если вариант затрагивает обучение, агенту `language-teacher`. Покажи рендер, назови плюсы и минусы каждого варианта с учётом их замечаний и порекомендуй один. Пользователь выбирает.
4. Только после выбора добавь выбранный вариант в `design/Tatar App Screens.dc.html` (новый номер экрана или состояние) и перерендери `design/screens/NN.png`.
5. Затем реализуй в Compose. Если нужен новый токен, он сначала появляется в `TamyrColors/TamyrShapes/TamyrSpacing/TamyrSizes`.

## Холст и экран

- Экран: `390×844`, фон `#F3EEDF`, рамка `1px #E5DEC6`, радиус `28px`, тень `0 14px 36px rgba(61,58,45,.14)`, `overflow:hidden`.
- Первая строка экрана — статус-бар (`9:41`, `13px`, bold, `#5A5642`).
- Подпись над экраном: моно-шрифт `12px`, `#5A5642`, вид `NN · название`; на экране `data-screen-label="NN Название"`.
- Боковой отступ экрана `24px`, нижний `36px` (у системной зоны). Контент прижимается вниз через `margin-top:auto`.

## Токены (как в `TamyrColors`)

| Роль | Значение |
|---|---|
| Фон / поверхность / приглушённая заливка | `#F3EEDF` / `#FFFCF3` / `#EAE3CB` |
| Граница / сильная граница / пунктир | `#E5DEC6` / `#D9CFB2` / `#C9C0A4` |
| Текст основной / вторичный / выключенный | `#3D3A2D` / `#5A5642` / `#A39D85` |
| Primary (зелёный) + тень + текст на нём | `#3B6B45` + `#2C5234` + `#F3EEDF` |
| Accent (терракота) + тень + мягкая тень | `#B5522F` + `#8A4326` + `#E0C9BC` |
| Золото / текст по золоту / контейнер | `#C99A34` / `#8A6F1F` / `#EFE6C8` |
| Успех (контейнер, граница) | `#D9EFD8`, `#A9CBA8` |
| Ошибка (контейнер, граница) | `#F4DFD4`, `#DFB9A5` |

Новых цветов не придумывай. Если без нового не обойтись, предложи его как токен и объясни, зачем.

## Форма и размеры

- Радиусы: тег `8`, чип `11`, ответ/поле `13`, кнопка `14`, карточка `16`, плитка `14`, круг `50%`.
- Высоты: главная кнопка `54`, вторичная `50`, поле `52`, вариант ответа `56`, переключатель `42`, прогресс `10`.
- Шаги отступов: `4, 6, 8, 12, 16, 20, 24, 32, 36`.
- Шрифт PT Sans: заголовок экрана `22/700`, большой заголовок `26/700`, кнопка `17/700`, подпись поля `14/700`, основной `15–16`, подсказка `13–14`.
- **«3D»-тень**: у нажимаемых элементов есть сплошная нижняя тень без размытия: `box-shadow:0 3px 0 <тёмный оттенок цвета элемента>`. Для светлых карточек это `0 3px 0 #E5DEC6`. Размытая тень (`0 14px 36px`) только у рамки экрана и всплывающих слоёв.
- Акцентное состояние поля или варианта: рамка `2px` цвета primary (фокус) или accent (выбран/ошибка).

## Язык и тон

- Заголовки и кнопки двуязычные: `Татарский · Русский` («Керергә · Войти», «Дөрес! · Верно!»). Только что-то из этого — допустимо, если есть пояснение.
- Тон дружелюбный, про Мыраужана («Мыраужан ищет твои уроки…», «Мыраужан подождёт»).
- Любой новый татарский текст помечай «needs native-speaker review» и в макете, и в коде. Не придумывай татарские фразы, которых не знаешь.

## Узнаваемые приёмы

- Маркеры бренда: три ромба (`rotate(45deg)`) цветов accent, gold, primary; жизни — ромбы accent.
- Семантика: зелёный контейнер = верно, терракотовый = ошибка/внимание, золотой = информация/награда.
- Маскот Мыраужан (SVG из `design/mascot/*.svg`) — на состояниях и в панелях ответа; позы описаны в `design/mascot-prompt.md`.
- Всплывающая панель ответа в квизе (экран 05) — ближайший прообраз любого уведомления: цветной контейнер, рамка сверху, иконка/маскот слева, заголовок `18/700` и подпись `13`.

## Чего избегать

- Системных элементов Material/iOS (тосты, алерты), чужих иконок и логотипов брендов: заглушки провайдеров в макете — цветные метки, и это помечено `TODO(design)`.
- Закрывать новым слоем важные элементы экрана (кнопка «назад», заголовок, главная кнопка).
- Рисовать только светлую тему: тёмной в макете пока нет.
- Размеров и цветов «на глаз»: каждое значение должно быть в таблицах выше.
